# (카페/바 레시피 암기 도우미)

## 대상 사용자

- (카페나 바에서 근무하며 단기간에 많은 레시피를 외워야 하는 아르바이트생 / 본인 매장만의 커스텀 레시피를 반복해서 학습하고 싶은 사용자)

## 사용 목적

- (메뉴별 레시피/용량/제조 순서 완벽 암기 및 숙달)

## 화면 구성과 동작

- 레시피 등록 화면 : 메뉴 이름, 재료명, 용량, 단위, 제조 순서 및 방법을 입력하는 칸이 나뉘어 있음
- 시작하기 버튼을 누르면 해당 데이터가 브라우저의 LocalStorage에 저장되고, 단계 선택란으로 넘어감 
- 단계 선택 화면 : '달걀(기초)', '병아리(중간)', '닭(심화)' 세 가지 버튼 중 자유롭게 선택 가능, 각 단계별 심볼이 존재(달걀, 병아리, 닭)하고, 이를 클릭하면 각 단계로 진입
- 퀴즈 화면 (달걀): 레시피 정보가 주어지면 해당 메뉴를 드래그 앤 드롭으로 연결, 정답 시: 달걀이 빛나는 이펙트와 함께 "맞았어요! OO 레시피입니다." 출력 후 다음 문제 이동, 오답 시: 정답 위치에 금색 테두리 표시,와 함께 "이 레시피는 OO 메뉴입니다. 다시 찾아보세요." 출력
- 퀴즈 화면 (병아리): 레시피 내용 중 틀린 부분을 찾는 객관식 문항 제공, 정답 시: 병아리가 빛나는 이펙트와 함께 "맞았어요! OO 레시피입니다." 출력 후 다음 문제 이동, 오답 시: 선택한 오답에 빨간 줄을 긋고, 옆에 주석 형태로 틀린 이유 설명. 객관식의 오답 생성은 숫자(예:재료 용량, 단위, 조리 시간 등)를 임의로 바꿔서 생성
- 퀴즈 화면 (닭):메뉴 이름만 보고 재료, 용량, 순서를 주관식으로 전체 작성. 정답 시: 닭이 빛나는 이펙트와 함께 "맞았어요! OO 레시피입니다." 출력 후 다음 문제 이동, 오답 시: 정답과 제출 답안을 양옆에 나란히 배치(비교 뷰)하고 틀린 글자만 빨간색으로 표시
- 각 단계별 5문제씩 제공, 맞힌 비율(%)과 '시도 정답 4 / 5개 · 틀린 레시피 1회’ 같은 줄, ‘다시 연습하기’ 버튼이 나옵니다.
- 전체 디자인 컨셉은 '달걀-병아리-닭'컨셉에 맞춰 귀여운 캐릭터 느낌으로 진행

## 필요한 자료

- 사용자가 직접 입력할 레시피 데이터 (메뉴명, 재료 리스트, 용량, 단위, 제조 순서 및 방법)
- 단계별 피드백 메시지 및 시각 효과(빛나는 효과, 금색 테두리, 빨간 줄 등)

## 완료 기준

- 사용자가 입력한 레시피가 브라우저를 새로고침해도 유지되어야 함 (LocalStorage 활용)
- 3가지 단계(달걀, 병아리, 닭벼슬)에서 사용자의 선택에 따라 정답, 오답에 따른 연출이 정상적으로 작동해야 함
- 각 단계별 오답일 시, 맞힐 때까지 다음 문제로 넘어가지 않습니다.
- 별도의 서버나 로그인 없이 HTML 파일 실행만으로 모든 기능이 동작해야 함
- 주관식 채점 시 맥락적으로 '재료명', '용량', '제조 순서 및 방법'이 모두 일치해야 정답으로 처리되어야 함

## 한계 및 비목표

(기획 단계에서 초안을 작성하고, 최종 HTML에 맞게 수정합니다)

1. 이미지 미지원 : 현재 기획에서는 텍스트 기반 레시피만 다루며, 메뉴 사진 등록 기능은 제외함
2. 레시피를 바탕으로 실제로 만드는 실습 과정은 연습할 수 없습니다.
3. 레시피의 내용의 수정 권한은 없습니다.

## 검증 방법

- 레시피를 등록한 후, 각 단계별 퀴즈에서 의도적으로 정답과 오답을 입력하여 기획한 피드백(이펙트, 메시지, 비교 뷰)이 정확히 출력되는지 확인
