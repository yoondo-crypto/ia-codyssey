# 나만의 영화 티어리스트 기획서

## 1. 누가 쓰나

- 사용자는 **본인 1명**이다.
- 개인적으로 본 영화들을 취향에 따라 정리하기 위해 사용한다.

---

## 2. 무엇을 하려고

- 영화들을 **S / A / B / C / D / F** 등급으로 나누어 정리한다.
- 모든 영화는 처음에 **미분류** 영역에서 시작한다.
- 사용자는 영화를 드래그해서 원하는 티어로 옮긴다.
- 티어리스트에 적용한 개인 기준을 해시태그 형태로 기록한다.

예시:

```text
적용 기준 : #서사 #연출 #메시지
```

---

## 3. 화면과 동작

### 화면 제목

```text
나만의 영화 티어리스트
```

### 화면 기준

- **PC 화면 기준**으로 제작한다.

### 주요 영역

- 제목 영역
- 해시태그 기준 입력란
- 미분류 영역
- S / A / B / C / D / F 티어 영역
- 초기화 버튼

### 동작

- 모든 영화는 처음에 **미분류**에 배치된다.
- 영화 이름 박스를 드래그해서 S~F 티어로 이동할 수 있다.
- 티어에 배치한 영화도 다시 **미분류로 이동 가능**하다.
- 영화 배치는 브라우저에 저장되어 **새로고침 후에도 유지**된다.
- 해시태그 기준 입력란의 내용도 브라우저에 저장되어 **새로고침 후에도 유지**된다.
- 초기화 버튼을 누르면 **영화 배치만 초기화**된다.
- 초기화해도 해시태그 기준 내용은 유지된다.

### 디자인 방향

- 전체 분위기: **어두운 배경의 영화관 느낌**
- 티어 색상:
  - S~F 순서로 **빨강 → 주황 → 노랑 → 흰색 계열 스펙트럼**
- 영화 이름 박스:
  - iOS 앱 아이콘처럼 **모서리가 둥근 형태**
  - 드래그 앤 드롭이 가능해야 함

## 4. 필요한 자료

### 영화 목록

- 기생충
- 인터스텔라
- 라라랜드
- 센과 치히로의 행방불명
- 어벤져스: 엔드게임
- 범죄도시
- 타이타닉
- 토이 스토리

### 저장해야 하는 데이터

- 각 영화가 어느 영역에 있는지에 대한 배치 정보
  - 미분류
  - S
  - A
  - B
  - C
  - D
  - F
- 해시태그 기준 입력란의 텍스트

### 저장 방식

- 브라우저 내부 저장 방식 사용
- 구체적으로는 웹페이지에서 사용할 수 있는 **로컬 저장소 방식**을 사용하면 됨

---

## 5. 완성 기준

- 웹페이지 제목이 **나만의 영화 티어리스트**로 표시된다.
- 처음 실행 시 모든 영화가 **미분류** 영역에 있다.
- 사용자가 영화를 드래그해서 S~F 티어로 이동할 수 있다.
- 티어에 있는 영화를 다시 미분류로 이동할 수 있다.
- 영화 배치가 새로고침 후에도 유지된다.
- 해시태그 기준 입력란을 직접 수정할 수 있다.
- 해시태그 기준 내용이 새로고침 후에도 유지된다.
- 초기화 버튼을 누르면 영화 배치만 초기화된다.
- 초기화 후에도 해시태그 기준 내용은 유지된다.
- 어두운 영화관 분위기의 디자인이 적용된다.
- S~F 티어 색상이 빨강, 주황, 노랑, 흰색 계열의 스펙트럼을 가진다.
- 영화 이름 박스는 둥근 모서리 형태로 표시된다.
